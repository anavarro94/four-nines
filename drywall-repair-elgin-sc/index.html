Drywall repair FAQ

Can you match my wall texture?

Yes. We match common textures like orange peel and knockdown. A close-up photo helps us plan.

Do you paint after the patch?

Yes. If you have the leftover paint, we use it. If not, we can get it color matched.

How long does it take?

Small patches are usually done in one visit. Bigger repairs can need a second short visit so the mud dries before painting.

How can I pay?

Cash, Zelle, Venmo or Apple Pay.
